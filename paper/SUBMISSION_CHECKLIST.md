# Applied Intelligence submission checklist

The files in this directory already use the official Springer Nature `sn-jnl` class and `sn-basic` numbered reference style. The submission package is flat, contains 42 validated bibliography entries, uses a 150–250-word unstructured abstract, supplies six keywords, limits heading depth to three levels, and numbers figures continuously from Fig. 1 to Fig. 13.

## Required author input before submission

- Replace the commented author/affiliation block in `PBIR_GIFT_Applied_Intelligence.tex`.
- Add corresponding-author email and ORCID identifiers where available.
- Replace the visible Funding, Competing interests, and Author contributions placeholders with accurate statements.
- Replace the prospective code-availability wording with the final public GitHub URL and, preferably, an archived DOI.
- Confirm whether manuscript-writing use of generative AI requires a disclosure under the journal's current policy. LLM use as the studied method is already described in the Methods.
- Confirm the repository software license with the original GIFT rights holders.

## Editable-source ZIP

- `PBIR_GIFT_Applied_Intelligence.tex`
- `references.bib`
- `sn-jnl.cls`, `sn-basic.bst`
- `Fig01.png`, `Fig02.pdf` through `Fig13.pdf`

Keep all source files at the ZIP root; do not use subdirectories. Upload the compiled
`PBIR_GIFT_Applied_Intelligence.pdf` as the manuscript PDF alongside the source ZIP.

Do not submit the generated `.bbl`, build script, build logs, or `citation_audit.md`
unless the editor requests them.
