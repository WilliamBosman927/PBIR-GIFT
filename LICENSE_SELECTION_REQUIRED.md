# Software license decision required

The upstream GIFT repository did not expose an explicit software license when this release was prepared. A public GitHub repository without a license remains protected by default copyright and does not grant reuse rights.

Before publication, obtain any required authorization from the original rights holders and add the agreed license. Do not label the software MIT, Apache-2.0, GPL, or another license without that authorization. The `data/` files have separate Apache-2.0 provenance documented in `data/NOTICE`.
